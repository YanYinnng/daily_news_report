# 微信公众号搜索与读取

## 选取读取路径

- **找文章，只有主题或标题：** 用网页搜索，例如 `site:mp.weixin.qq.com/s "主题" "公众号名"`；必要时再搜完整标题、日期区间以及发布者官网。搜索结果只是候选，核对标题、公众号、发布时间和原文链接。关键词搜索依赖公开索引，不承诺搜全微信；不要把搜索摘要当成正文。
- **找指定公众号的近期更新：** 用本技能的 `accounts` 找本机清单中的准确名称或标识，再用 `recent` 从微信读书获取文章列表。新公众号不必加入项目配置：有经过核对、带 `__biz` 的微信原文长链接即可用 `recent --source-url`。短链接不是公众号身份；先从公开原文、发布者官网或可信出处核对，遇到同名号让用户提供一篇原文链接。项目清单之外不等同于用户未关注；不能从读取成功推断关注状态。
- **已经有原文链接：** 用 `read` 打开该篇公开微信链接，或直接读取 `recent` 返回的微信读书文章链接。如果公开页面打不开，单独确认该篇的公众号、标题、日期；用同号的微信读书列表匹配同一篇，再读匹配项。只有最新一篇、同标题但日期不明或搜索片段时，标记为未核实，不拿来替代原文。优先引用原文链接；需要时注明正文来源和是否有 OCR 或截断。

本技能复用安装在 Windows 本机的项目 Python 环境、会话和身份缓存。运行 `scripts/install_skill.ps1` 安装；默认项目入口是 `src.article_reader`，安装后的 `scripts/wechat_articles.py` 只是调用入口，实际路径见技能根目录的 `project-root.txt`。可从任意本机聊天调用；若当前主机无法访问该项目，仍可做公开网页搜索并说明本机会话不可用。常用命令见[本机用法](references/local-reader.md)。

## 图片正文和海报

- 用户给出公众号原文链接时直接运行 `read`。纯图片正文会自动复用项目的 Windows 本地 OCR，长图按段识别。公开文章同时有文字和图片、且用户要求读图或关键信息在海报中时，给 `read` 加 `--include-images`，保留网页原文并附上图片识别文字。
- 读取海报里的具体信息时，在浏览器打开原图，长图按相关版块逐段看；用 `windows_ocr_unverified` 或 `html_with_windows_ocr_unverified` 的识别稿定位。岗位、地点、薪资、届别、截止日期和投递入口以原图可辨认的内容为准；看不清的地方标明未核验。遇到 `image_ocr_failed` 或 `image_ocr_status: unavailable` 也可直接看图；原图看不清时请用户提供清晰截图。

## 常规路径失败时

1. **公开页面验证、失效或仅有搜索摘要：** 停止重复请求该页面。可以尝试同篇的可核对微信读书链接或发布者官网；也可以请用户在微信打开原文后提供链接、可访问正文或截图。不要根据片段编造摘要。
2. **未登录或登录过期（通常是 `-2012`）：** 先运行正常读取，项目采集器会尝试一次正常续期。收到 `login_required`（本机会话缺失或正常续期未恢复）才运行 `login`，把**本次新生成**的二维码显示给用户，提醒用手机微信扫码并确认。等待登录结果，然后实读列表和一篇正文；二维码过期需要重新生成，网页登录成功不等于文章已授权。
3. **已登录但文章列表返回 `-2041`、微信读书显示验证或权限受限：** 停止本轮，不要反复扫码。请用户在手机上打开 **微信读书 → 书架 → 文章收藏 → 点击已收藏的公众号名称**（不要只点文章标题），按页面真实提示完成授权或安全验证，并确认是否能看到**多篇文章列表**。没有「文章收藏」时，先在微信打开一篇公众号文章，点右上角 **… → 更多打开方式 → 微信读书**，如有提示按提示完成，再回书架检查。不要把 `-2041` 直接等同于授权过期。
4. **用户确认已处理后：** 查 `status`。如果本地仍在保护等待期，告知何时结束，不删除限制标记；到期后仅复查一个已知账号的列表和最多一篇正文。成功后再继续目标；仍失败则报实际结果，让用户在手机上读原文或提供正文。空列表是有效响应，不代表该号从未发布文章；历史窗口未覆盖也不等于没有文章。

只做当前请求需要的有限查询，同一会话串行、按项目的请求间隔读取。保持登录凭据仅在本机，不展示或复制会话文件。技能不启动日报、定时任务、模型摘要 API、邮件或付费数据源；按用户要求在当前聊天内总结已读内容即可。
